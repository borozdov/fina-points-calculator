# Аналитика

Счётчик Метрики — **107084687** (`fina-points-calculator`, fina.borozdov.ru). Все события
отправляются через [trackGoal()](js/helpers/analytics.js), в `app.js` — через обёртку
`this.goal()`, которая молчит во время восстановления расчёта из избранного (иначе
программные клики по кнопкам плодили бы ложные цели).

**Имена событий менять нельзя, не поменяв условие цели в Метрике** — цель ищет точное
совпадение строки.

## Выход на borozdov.ru

| Событие   | Цель            |
| --------- | --------------- |
| `to_site` | Переход на сайт |

Ссылка в подвале ведёт на
`https://borozdov.ru/?utm_source=fina.borozdov.ru&utm_medium=referral&utm_campaign=author_footer`.

Смотреть приход **на стороне borozdov.ru** (счётчик `108499351`): сегмент
**«Из калькулятора FINA»** (`ym:s:UTMSource=='fina.borozdov.ru'`), либо отчёт
«Источники → Метки UTM». Referrer тоже долетает — `meta[name=referrer]` стоит в
`strict-origin-when-cross-origin`, то есть borozdov.ru видит `https://fina.borozdov.ru/`.
UTM нужен как надёжный дубль: поддомены одного домена Метрика может посчитать внутренним
переходом.

## Чистка 02.09.2026

Со счётчика удалено 10 целей, чтобы в списке остались только те, у которых есть событие
в коде:

- `Смена темы (Выбор цвета)` — ждала кнопку `color-toggle`, которой в приложении нет;
- `Клик «Поддержать»` — донат из шапки удалён;
- `Скачивания`, `Смена темы (тёмная/светлая)`, `Поделиться qr` — «кнопочные» цели,
  дублировали `install_open`, `theme_toggle` и `qr_share_click`;
- четыре CRM-автоцели — интеграции нет;
- `Автоцель: отправка формы` — submit форм в приложении заблокирован и служит только для
  скрытия клавиатуры, то есть цель считала нажатия Enter в поле.

Сейчас все 28 целей — типа `action`, то есть заводятся только через `trackGoal()`.
Заводить «кнопочные» цели по `btn_id` не стоит: они молча ломаются при любом
переименовании элемента, тогда как рассинхрон `action`-цели виден по этому файлу.
